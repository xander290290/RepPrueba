Código interno del backend PHP, fuera del document root `public\`.

- `config\`: configuración de la aplicación y variables de entorno.
- `controllers\`: manejadores de peticiones HTTP.
- `database\`: conexión PDO a MySQL (`database\connection.php`).
- `models\`: entidades y reglas del dominio público.
- `repositories\`: consultas parametrizadas y persistencia.
- `routes\`: rutas HTTP iniciales (`routes\api.php`).
- `services\`: casos de uso y lógica de aplicación.

Las rutas funcionales de contenidos se añadirán cuando se apruebe e implemente
el esquema de datos público.
