Documentación específica de la web pública. La memoria deja el framework del frontend a elección del equipo; se ha elegido Astro con TypeScript. El backend usa PHP sin framework y MySQL, seleccionados entre las opciones de la memoria. La intranet permanece como una aplicación independiente, enlazada desde el sitio pero sin compartir autenticación ni sesión.

- `arranque-web-publica.md`: requisitos y comandos PowerShell para instalar dependencias, crear la configuración local, arrancar Astro, comprobar tipos y generar/previsualizar la compilación. Aclara que el backend PHP todavía no está implementado.
- `contenido.txt`: este índice de la carpeta.
