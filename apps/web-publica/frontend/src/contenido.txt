Código fuente del frontend Astro con TypeScript.

- `components\`: layout común, cabecera/navegación y pie.
- `lib\`: cliente tipado para consultar la API pública durante el renderizado.
- `pages\`: portada, páginas informativas y noticias renderizadas en servidor.
- `styles\`: hoja de estilos global y adaptable.
- `env.d.ts`: tipos de Astro y de la variable `PUBLIC_INTRANET_URL`.

Las páginas públicas se renderizan con Astro Node y obtienen sus datos del backend PHP/MySQL en cada petición.
